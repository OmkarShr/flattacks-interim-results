# FLattacks Interim Baseline Results

Public, read-only snapshot of current development results for V2, DAGER, FILM, and a gradient-only causal LAMP feasibility arm on frozen Pythia checkpoints.

## Scope

- Development rows only; no held-out final-pool evaluation
- One aggregate at seed 0 per completed cell
- Seven completed non-LAMP cells across Pythia-160m and Pythia-410m
- Two Pythia-160m LAMP feasibility checks
- V2 oracle-assisted assembly is explicitly diagnostic, not an autonomous score

Open `index.html` or visit the repository's GitHub Pages URL. Machine-readable values are in `results.json`.
